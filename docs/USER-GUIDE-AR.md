# دليل استخدام منصة Bookora — Universal Booking SaaS

**نظام حجز شامل وقابل لإعادة الاستخدام (White-label) للعيادات والصالونات والجيم والاستشارات وغيرها**

---

## 1. نظرة عامة وهدف الموقع

**Bookora** منصة SaaS للحجوزات قابلة للتخصيص (White-label) تمكن أي نشاط تجاري من إدارة خدماته وموظفيه وعملائه ومواعيده بسهولة.

### الهدف:
- توفير نظام حجز جاهز للبيع أو الاستخدام الفوري.
- دعم أدوار متعددة (مالك، مدير، موظف، عميل).
- دعم كامل للعربي والإنجليزي مع RTL.
- محرك توافر ذكي يمنع التعارض في المواعيد.

---

## 2. الأدوار والصلاحيات

| الدور | الوصف | الصلاحيات |
|-------|--------|-----------|
| **Super Admin** | مدير المنصة | إدارة كل الأعمال |
| **business_owner (Owner)** | مالك النشاط | إدارة كاملة للنشاط والموظفين والخدمات |
| **manager** | مدير | إدارة الحجوزات والموظفين |
| **staff** | موظف / مقدم خدمة | عرض مواعيده وتحديثها |
| **customer** | عميل | حجز مواعيد، إلغاء، إعادة جدولة، تقييم |

### حسابات تجريبية (كلمة المرور: `Password123`)

| البريد | الدور |
|--------|-------|
| owner@bookora.app | business_owner |
| manager@bookora.app | manager |
| staff@bookora.app | staff |
| customer@bookora.app | customer |

Business slug تجريبي: `cairo-care`

---

## 3. دورة العميل

1. الدخول للمنصة أو رابط النشاط.
2. اختيار الخدمة والموظف والوقت المتاح.
3. تأكيد الحجز.
4. استلام إشعار.
5. إمكانية الإلغاء أو إعادة الجدولة.
6. بعد الخدمة: كتابة تقييم.

---

## 4. دورة المالك / المدير

1. إعداد النشاط (الاسم، الشعار، الألوان).
2. إضافة التصنيفات والخدمات.
3. إضافة الموظفين وربطهم بالخدمات.
4. تحديد أوقات العمل والتوافر.
5. متابعة الحجوزات من لوحة التحكم.
6. عرض التحليلات والإيرادات.
7. الرد على التقييمات.

---

## 5. الميزات الرئيسية

- نظام White-label (ألوان وشعار قابل للتغيير).
- عربي + إنجليزي كامل + RTL/LTR.
- أدوار متعددة مع صلاحيات.
- محرك توافر مع حماية من التعارض.
- حجوزات (إنشاء، إلغاء، إعادة جدولة).
- لوحات تحكم للـ Admin والعميل.
- تحليلات وإحصائيات.
- إشعارات داخل التطبيق.
- تقييمات ومراجعات.
- أمان قوي (Helmet, Rate Limit, JWT + HTTP-only cookies, Zod).

---

## 6. التقنيات

**Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, TanStack Query, i18next, React Hook Form + Zod, Recharts  
**Backend:** Node.js, Express, TypeScript, MongoDB, Mongoose, JWT, bcrypt
